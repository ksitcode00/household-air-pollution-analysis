# Data Availability

Participant-level field, health, household, and monitoring data are not included in this public repository. The data are restricted by research-data and manuscript-review requirements.

For authorized local review, place the source dataset at:

```text
data/private/indoor_air_quality_raw.xlsx
```

The private-data directory is excluded from version control. This repository provides the analytical workflow, public documentation, and aggregate findings without exposing participant records.

## Analytical structure

The workflow uses household-level information on cookstove type, indoor pollutant monitoring, kitchen and structural characteristics, electricity access, village-program context, and respiratory-health outcomes. Pollutant outcomes include PM10, PM2.5, PM1, black carbon, and carbon monoxide measured over 24-hour and cooking-period windows.
